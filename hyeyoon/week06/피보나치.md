
# 문제

피보나치 수는 다음과 같이 정의된다.

- F(0) = 0
- F(1) = 1
- F(n) = F(n-1) + F(n-2)

2 이상의 n이 입력되었을 때, n번째 피보나치 수를 1234567로 나눈 나머지를 반환한다.

---

# 풀이 1 - 재귀

재귀함수를 이용하여 피보나치 수의 정의를 그대로 구현하였다.

```python
def solution(n):
    def fib(n):
        if n == 0:
            return 0

        if n == 1:
            return 1

        return fib(n - 1) + fib(n - 2)

    return fib(n)
```

## 접근

피보나치 수의 정의가

```text
F(n) = F(n-1) + F(n-2)
```

이므로 `fib(n)`을 구하기 위해 `fib(n-1)`과 `fib(n-2)`를 재귀적으로 호출하였다.

예를 들어 `fib(5)`를 호출하면 다음과 같이 재귀 호출이 뻗어나간다.

```text
                    fib(5)
                 /          \
             fib(4)         fib(3)
            /     \         /     \
        fib(3)   fib(2)  fib(2)   fib(1)
        /   \     /   \    /   \
     fib(2) fib(1) ...
```

---

# 시간복잡도

처음에는 재귀 함수 한 번의 연산 자체보다, `fib(n)`을 호출했을 때 만들어지는 **재귀 트리의 전체 노드 개수**를 세면 된다고 생각했다.

하나의 `fib()`에서 최대 2개의 새로운 `fib()`가 호출된다.

따라서 트리가 완전 이진 트리처럼 뻗는다고 생각하면 각 level의 최대 노드 수는 다음과 같다.

```text
level 0 : 1
level 1 : 2
level 2 : 4
level 3 : 8
...
level n : 2^n
```

즉 전체 노드의 개수는

```text
1 + 2 + 4 + 8 + ... + 2^n
```

이다.

이는 등비수열의 합 공식에 의해

```text
1 + 2 + 2² + ... + 2^n
= 2^(n+1) - 1
```

이 된다.

따라서 상한을 기준으로 시간복잡도는

```text
O(2^n)
```

으로 볼 수 있다.

정확히 말하면 실제 피보나치 재귀 트리는 모든 노드가 항상 두 개의 자식을 갖는 완전 이진 트리는 아니다.

따라서 실제 호출 횟수는 피보나치 수의 증가량과 관련되어 `O(φ^n)`에 가깝지만, 재귀 호출이 최대 2개씩 뻗어나간다는 것을 기준으로 상한을 잡아 `O(2^n)`으로 표현할 수 있다.

핵심은 같은 값을 여러 번 계산한다는 것이다.

예를 들어

```text
fib(5)
├── fib(4)
│   └── fib(3)
│       └── fib(2)
│
└── fib(3)
    └── fib(2)
```

처럼 `fib(3)`, `fib(2)` 등이 계속 중복해서 계산된다.

---

# 공간복잡도

시간복잡도처럼 재귀 트리의 **전체 노드 개수**를 세는 것이 아니다.

공간복잡도에서는 특정 순간에 메모리에 동시에 존재하는 재귀 호출의 개수를 생각한다.

예를 들어 `fib(5)`를 실행하면 호출 스택은 한쪽으로 최대 다음과 같이 쌓인다.

```text
fib(5)
↓
fib(4)
↓
fib(3)
↓
fib(2)
↓
fib(1)
```

한쪽 경로를 따라 최대 약 n개의 함수 호출이 동시에 Call Stack에 존재한다.

따라서 공간복잡도는

```text
O(n)
```

이다.

즉,

```text
시간복잡도 → 재귀 트리 전체에서 실행되는 호출 수 → O(2^n)

공간복잡도 → 동시에 쌓여 있는 최대 재귀 깊이 → O(n)
```

으로 구분할 수 있다.

# 주의

위 코드는 피보나치 재귀 구조를 이해하기 위한 코드이지만, 이 문제의 제한사항인

```text
2 <= n <= 100,000
```

에서는 실제 정답 코드로 사용할 수 없다.

이유는 다음과 같다.

1. 같은 `fib()` 값을 반복해서 계산하여 시간복잡도가 매우 크다.
2. 재귀 깊이가 최대 O(n)까지 증가하여 Python의 재귀 깊이 제한에 걸릴 수 있다.
3. 문제에서 요구하는 `1234567`로 나눈 나머지 연산이 현재 코드에는 포함되어 있지 않다.

따라서 실제 문제에서는 이전에 계산한 피보나치 값을 활용하는 DP 방식으로 개선할 수 있다.

---

# 시간복잡도

O(2^n)

# 공간복잡도

O(n)

# 배운 점


def solution(n):

    dp = [-1] * (n + 1)

    def fib(n):

        if n == 1:
            dp[1] = 1
            return 1

        if n == 0:
            dp[0] = 0
            return 0

        # 아직 계산하지 않았다면 계산
        if dp[n] == -1:
            dp[n] = (fib(n - 1) + fib(n - 2)) % 1234567

        # 이미 계산했다면 위 if를 건너뛰고
        # 저장되어 있는 값을 그대로 return
        return dp[n]

    return fib(n)
